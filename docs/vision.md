# Visión

MyChecklist es una app de listas y tareas para quien trabaja con código y con agentes.

## Qué la distingue

- **Items en Markdown** con imágenes, links y backlinks `[[item]]`. El texto es la fuente de verdad.
- **Links vivos a GitHub:** issues, PRs y branches con su estado (abierto, cerrado, mergeado, CI).
- **Listas por área** (programación, diseño, …) dentro de un espacio personal o de una organización.
- **Una API para agentes en Code Mode:** en vez de una herramienta por operación, el agente escribe código contra una
  API tipada y lo ejecuta en un sandbox. Varias llamadas en una sola ejecución, con muchos menos tokens.
- **Web y desktop** contra el mismo servidor.
- **Importar y exportar** sin pérdida (JSON) y en Markdown (`- [ ]`).
- **Temas** de la casa.

## Para quién

- Uso personal: público en `checklist.wefaber.net`, con login de GitHub.
- Organizaciones: equipos con roles, solo por la tailnet.
